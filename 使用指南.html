🧭 炼知 ReKnow v6 · 使用指南

从一片可以走进去的「炼金宇宙」开始：挑一颗星、学懂它、点亮它，再把收藏炼成你自己的回答。

1快速上手（三步）

1
进宇宙，挑一颗星

点顶部「🌌 炼金宇宙」：每一颗星球 = 你收藏夹里的一篇好回答。点星体弹出卡片，点「⛏ 开始学这篇」进入拆解流；点热榜可直接飞到当红星球。

2
拆解 → 学懂

在拆解页点知识块标记「读懂」，用四种学习方式之一通关（闯关 / 快问快答 / 听讲 / AI 开杠）。回到宇宙你会发现：这颗星被点亮了 ✨。

3
图谱 → 回流

DIY 你的思维图谱 → 「融会贯通」→ 发回知乎或存进知识库，炉火值 +200。

2🌌 炼金宇宙怎么玩

想做什么怎么做
旋转 / 缩放 / 平移视角按住左键拖拽旋转 · 滚轮缩放（相机默认缓慢自转）
查看某个选题点星体 → 左侧卡片显示问题 / 答主 / 热度 / 是否已学懂
开始学习星体卡点「⛏ 开始学这篇」→ 自动回到收藏夹流程第 2 步

🦊 看山会陪你

看山悬浮在炼金炉旁当向导：点它会跟你玩；它还会随天气换动作（晴天招手、雨夜躲雨、雪夜搓手…）。星星大小 = 热度；点亮的星 = 你已学懂。

4✏️ 原文圈点与批注

操作方法
打开原文星体卡「📖 看原文 · 圈点」或拆解页顶部「📖 原文圈点」，以知乎问答样式展示问题与高赞回答正文。
高亮在正文里选中一段文字，点浮动色块：黄蓝粉（默认当前色在右上工具条切换）。
加旁注选中文字 → 点浮动「📝」，写下你的理解 / 联想 / 问题；点正文里的 📝 角标可随时修改或删除。
管理批注阅读器底部列出全部圈点：点条目跳回原文位置；✕ 删除该条圈点。
恢复所有高亮与批注自动保存在本地（同一浏览器），重新打开同一篇自动还原。
📌 建议在「一段」内圈点：跨段选中会提示重新选择，这是为了保证高亮可被完整保存与还原。

7常见问题 FAQ

问题解答
为什么进入宇宙前白屏一下？首次进入需加载内置 3D 引擎（约 0.7MB，本地加载很快）；再次进入即秒开。
浏览器不支持 3D？会提示「当前浏览器不支持 WebGL」，其余功能不受影响（可用 Chrome / Edge 获得最佳体验）。
「实时」绿点什么时候亮？运行 node server.js 并用 http 打开页面后自动点亮；纯离线打开则为「本地演示数据」，功能一致。
音效可以关吗？可以，顶栏 🔊 一键切换；宇宙内音效同样受它控制。
进度 / 高亮会保存吗？都会保存在本地浏览器（进度 rkSave，圈点批注 rkUniOrig）；顶栏 ↺ 可清空进度。
数据是真的吗？赛事演示为预置示例收藏 + 少量实时演示；接入知乎 OAuth 后即来自你的真实收藏夹。
看山形象？知乎官方看山 GIF，仅赛事演示用途。
