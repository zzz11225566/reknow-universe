# 炼知 ReKnow · 炼金宇宙 —— 项目策划书

> 知乎黑客松 2026 · 主题二：知识炼金场
> 一句话定位：把用户收藏夹里尘封的优质回答「拆解 → 用第一性原理学懂 → 构建自己的思维导图」，并让整个过程发生在一座会呼吸的 3D「炼金宇宙」里。

---

## 一、我们解决什么问题

知乎用户的典型行为是「收藏即终点」：

- **收藏夹吃灰**：收藏 ≠ 学会，囤积焦虑远大于消化；
- **看完就忘**：缺少主动回忆与科学复习机制；
- **输出无门**：想写回答时组织不起观点；
- **碎片无体系**：知识散落各篇，形不成自己的地图。

缺的不是内容，而是把「别人的好内容」炼成「自己的能力」的那道工序。

## 二、核心理念（设计哲学）

| 理念 | 落地方式 |
|---|---|
| **易上手** | 双击即开、零安装、离线可演示；首次使用有看山（知乎吉祥物）全程引导 |
| **高效率** | 每篇回答被拆解为结构化知识点（主张 / 方法 / 原理 / 金句 / 误区 / 行动），拒绝逐字硬读 |
| **逻辑清晰** | 学习闭环五步：拆解 → 学懂 → 图谱 → 融会贯通 → 回流社区，每步状态可视 |
| **辅助并伴随用户成长** | 不是表面的徽章游戏，而是**功能层的"越用越像你"**：进库规则、拆解深度、学习流程、AI 行为、复习节奏全部可由用户调教（详见第五节「炼金配方」）；经验值保留，但升级所需经验逐级递增——等级越高越稀缺，成为长期陪伴的见证 |
| **用户可自定义** | 不止外观主题：用户可以决定"收什么、拆多深、学哪几步、AI 怎么对我、要不要复习"——产品适应人，而非人适应产品 |
| **第一性原理渗透** | 不止「学什么」，更追「为什么成立」：每个知识点都要求回溯到原理层；AI 开杠逼问模糊之处；思维图谱强迫用户建立概念间的因果连接 |

## 三、核心机制

1. **🛡️ AI 反对你**：学习检测阶段 AI 主动当「反对派」（温和 / 适中 / 激烈三档），与 AI 开杠可以强化记忆——把模糊之处顶到台面上。
2. **🔗 学习不孤立**：每块知识点学完都落到生活 / 学习 / 工作三张场景卡，避免「收藏了却用不上」。
3. **♻️ 回流社区**：学懂后一键生成自己的回答草稿 / 成果卡，发回知乎——收藏夹从「终点」变「起点」。

## 四、特色体验：炼金宇宙

把学习界面升维成一座沉浸式 3D 宇宙，让用户「走进」自己的收藏夹：

- **收藏 = 星体**：每篇收藏的回答是星海中的一颗星球，大小映射热度；
- **理解 = 炉火**：学懂一篇即点亮一颗星；宇宙中央的炼金炉，炉火随总经验值越烧越旺；
- **炼金链路**：知识点之间的关联化作贝塞尔光链，光点沿链路流动；
- **环境有生命**：真实时间驱动昼夜（黎明 / 白昼 / 黄昏 / 深夜自动调色）；天气系统（晴 / 多云 / 雨夜 / 雪夜 / 极光）一键切换，1.5 秒平滑过渡光影、雾、粒子；
- **看山同行**：知乎官方吉祥物看山驻守宇宙，随天气变化动作（晴天招手、雨夜躲雨、雪天搓手），是用户的陪伴化身；
- **原文圈点**：每篇回答的知乎样式原文支持三色高亮 + 旁注批注，自动保存、重开恢复；
- **热榜与搜索**：右侧热榜抽屉点击即「镜头飞行」到对应星球；搜索可过滤整个星海。

## 五、个性化系统：炼金配方（核心差异化）

「炼金配方」是 ReKnow 的灵魂机制：**每个用户的全部使用偏好被浓缩成一份"配方"**，产品按配方运转，配方随用户成长不断被调教——这才是真正的"伴随成长"。配方覆盖五个维度：

| 维度 | 用户的权力 |
|---|---|
| 📥 **进库规则** | 收藏夹进宇宙采用「手动挑 + AI 粗筛」两步流程，**每一步都可单独开关**：全手动、全 AI、或两者叠加 |
| 🔬 **拆解档位** | 预设三档：**浅尝**（3 个知识点，快速过）/ **标准**（结构化拆解）/ **深挖**（第一性原理追到底，强制追问"为什么成立"）；按篇可随时临时换档 |
| 🧩 **流程编排** | 五步学习闭环（拆解→学懂→图谱→融汇→回流）**可增、可关、可重排**：不写回答的用户可以把"回流"从主流程中收起——**环节不会丢失，入口始终保留在"流程管理"里，随时一键还原**，流程随需求变化而呼吸 |
| 🤖 **AI 配置** | AI 能力**通过 API 接入外部开源模型**，模型可替换：用户可配置自己的模型服务（兼容 OpenAI 格式的 base URL + Key + 模型名），官方提供默认配置，AI 的行为边界由所选模型与用户指令共同决定 |
| ⏰ **复习节奏** | **是否复习、何时复习完全由用户决定**：可以开间隔重复，可以按主题分别安排（工作类每周、兴趣类随缘），也可以完全关闭——产品不强迫 |

**配方的三种载体（全都要）：**

1. **设置页**：集中填表式管理整份配方，适合初次调教；
2. **边用边调**：每个功能旁有小齿轮 ⚙️，用到哪调到哪，系统默默记住并写回配方；
3. **配方文件**：配方可导出为 JSON 文件、可导入、可分享——"这是费曼粉的配置，拿走不谢"，让好的学习方法论可以像种子一样传播。

**成长体系**：保留经验值（炉火）与等级，但**升级所需经验逐级递增**——前期快速成长建立信心，后期每升一级都是真实的积累；知识库与思维图谱随配方长期演化，成为用户的第二大脑。

## 六、技术架构速览

- **前端**：原生 HTML/JS 单页应用 + Three.js（r160，本地内置，无 CDN、无构建，双击 `index.html` 即跑）；
- **后端**：纯 Node 零依赖 `server.js`（静态托管 + REST + WebSocket），将升级为 SQLite 数据库 + JWT 认证；
- **AI**：国内大模型 API（Key 仅存后端，前端不可见），驱动 AI 开杠与随时提问小窗；
- **数据源**：知乎官方 API（赛事提供）——用户 OAuth 授权后，收藏夹自动同步为宇宙中的星球；
- **白板**：tldraw 开源引擎嵌入，数据存云端账户。

## 七、合规与版权

- 知乎接入仅使用官方授权 API，遵守最小授权与 robots 协议，不碰任何逆向 / 抓取接口；
- AI 只做拆解 / 提问 / 反驳 / 整理，正文永远出自用户之手；
- 看山形象与知乎素材版权归知乎官方所有，仅赛事用途。

## 八、商业价值（简述）

Freemium 模式：基础学习闭环免费；无限炼金队列、深度拆解、复习调度、3D 主题皮肤、多人协作白板为订阅项；面向校园与企业培训提供团体版。
