## 2. 浏览器人工验收（重点，逐条勾）

打开 **http://localhost:8787**。

### 2.0 先挂上诊断条

访问 **http://localhost:8787/?diag=1&auto=uni** → 1.2 秒后自动进炼金宇宙，左下角出现绿色诊断条。

- [ ] 诊断条里 `errs: []`（这是"零报错"的硬证据）
- [ ] `three: true`、`shell: "on"`、`weather` 有值
- [ ] F12 控制台**只有一条** Three.js deprecation 提示（已知噪音），没有红色报错

### 2.1 六种天气 + 极光（需求④）

- [ ] 顶部天气带是 **6 个**按钮：☀️晴 / 🌤️多云 / 🌧️雨夜 / ⛈️**雷暴** / ❄️雪夜 / 🌌极光
- [ ] 逐个点一遍，每次约 1.5 秒平滑过渡（光影/雾/粒子一起变），**看山动作跟着换**
- [ ] 点 **⛈️ 雷暴**：天空压暗、雨更密，**随机劈闪电** + 全屏闪白 + 低频轰鸣（带耳机更明显）
- [ ] 点 **🌌 极光**：三层帘幕、**竖向丝状结构**在流动、底部青绿→上部品红紫、地平线有反光
- [ ] 极光下画面明显更通透（这一档会自动开 1.45× 超采样）
- [ ] 鼠标悬停任一按钮，能看到说明气泡（极光那条写"高分辨率极光帘幕…"）

> 想跳过点击直接看极光：`http://localhost:8787/?wx=aurora`
> 注意：如果「跟随实时」是亮的（绿点），点任意天气按钮会自动切成手动模式，不会再被后端推送顶掉。

### 2.2 电影级 + 玻璃液态 + 看山（需求③）

- [ ] 画面有暗角与四角压暗、轻微胶片颗粒、边缘微微色散（**镜头感**而不是贴图感）
- [ ] HUD（时钟/搜索/按钮/面板）都是**玻璃质感**：半透明 + 背景虚化 + 顶部液膜高光 + 缓慢流动的反光带
- [ ] **看山在左下角**，不在星海中央挡视野；尺寸小、不占中央
- [ ] 看山一直在**蹦跳/歪头**，鼠标悬停出现工具条 🐾 🔽 📌 🙈
- [ ] 点 🐾 会跳一下；点 📌 回左下角；点 🙈 藏起来（`Alt+F` 可召回）
- [ ] 用鼠标**拖看山**能换位置，松手自动吸附到最近的角
- [ ] 打开右侧面板（热榜/AI）时，看山会自动**让开**不叠在面板上

### 2.3 原文批注（需求②，这次修的就是它）

- [ ] 在宇宙里点一颗星体 → 「📖 看原文·圈点」（或拆解页右上「📖 原文圈点」）
- [ ] 首次打开自动弹出 **3 步引导**（① 选中一句话 ② 点色块 ③ 拉真实原文），可"不再提示"
- [ ] **拖选正文里的一句话** → 立刻弹出浮动工具条
- [ ] 点黄/蓝/粉色块 → **文字立刻被高亮**（重点：旧版在这里"点了没反应"）
- [ ] 点工具条的 📝 → 弹批注框 → 写字 → 保存 → 右侧列表出现这条
- [ ] **不用选中**：鼠标移到任意段落，左侧出现 ✏️ → 点它**整段一键批注**并弹出批注框
- [ ] 键盘：按 `1`/`2`/`3` 换颜色、按 `N` 对选中内容直接加批注
- [ ] 右侧列表点一条 → 正文对应位置会滚动并闪一下；点 ✕ 能删
- [ ] 刷新页面重进 → 高亮与批注**都还在**（存 localStorage `rkUniOrig`）

### 2.4 知乎真实原文（需求②）

- [ ] 阅读器顶部来源条写着「📄 演示原文（…）」+ 一个金色按钮「📥 拉取知乎原文（可批注）」
- [ ] 点它 → 变成「✅ 知乎真实原文 · 1044 字 · 21 段」，正文换成**知乎真实内容**（左侧有蓝色竖线标记）
- [ ] 在这段真实原文上**再批注一次** → 成功
- [ ] 点来源条的「知乎原链接 ↗」→ 新标签页打开知乎原文
- [ ] 点「🔄 重新拉取知乎原文」可再拉一次

### 2.5 AI 对话（需求②）

- [ ] 宇宙右上角有「🤖 AI · 热聊」按钮 → 打开后默认在「AI 对话」页签
- [ ] 右上状态显示 `DeepSeek · deepseek-chat（余额 xx）`（悬停看模型列表）
- [ ] 快捷提问有 6 个按钮（这篇到底在说什么 / 我哪里没懂 / 出 3 道题 / 记忆钩子 / 和我抬杠 / 梳理批注）
- [ ] 点「这篇到底在说什么？」→ 回答**逐字流式冒出来**（不是一次性蹦出）
- [ ] 回答带 **DeepSeek** 徽标
- [ ] 先在某篇原文里划两笔批注，再点「📝 帮我梳理批注」→ AI 会**引用你的批注**点评
- [ ] 自己在输入框提问，Ctrl+Enter 或点发送 → 正常回答

### 2.6 多人实时热点话题房间（需求②）

- [ ] AI 面板切到「🔥 热点房间」
- [ ] 话题列表是**知乎实时热榜**（条目来自真实知乎），上方标注"话题池：知乎实时热榜"
- [ ] 填个昵称 → 点一个话题 → 右侧显示「实时已连接 · N 人在线」（绿点亮）
- [ ] 「📖 拿它当原文批注」按钮能把该热点正文拉进阅读器批注
- [ ] **发一条消息** → 自己这边出现橙色气泡
- [ ] 输入 `@AI 这个热点的反面是什么` → 小炼加入讨论并把回答**广播给全房间**

**真正的多人验证（关键）**：
1. 再开一个浏览器窗口（或另一台同局域网设备访问 `http://<你的IP>:8787`）
2. 两个窗口都进「热点房间」→ **点同一个话题**
3. 两边都在线人数里看到对方；A 发消息 → **B 界面几乎同时出现**

### 2.7 拆解环节接知乎搜索（需求⑥）

- [ ] 回首页 → 随便点一篇 → 进到第 2 步「拆解」
- [ ] 拆解步骤**最上方**有「🔍 知乎原文对照」条（含搜索框 + 两个按钮）
- [ ] 点「🔍 搜索知乎原文」→ 出 8 条真实结果（标题 / 回答or文章 / 作者 / 赞同 / 摘要）
- [ ] 每条有「在知乎打开 ↗」「📖 用它做原文圈点批注」「🤖 问小炼这篇讲什么」三个动作
- [ ] 点「📖 用它做原文圈点批注」→ 阅读器打开，正文可批注
- [ ] 点「🤖 问小炼这篇讲什么」→ 自动进宇宙并让 AI 结合该原文讲解

### 2.8 AI 抬杠贴合用户原话（需求⑤）

- [ ] 进任一篇的第 3 步「学懂」→ 选「🛡️ AI 开杠」
- [ ] 先用**大白话**写一句你的理解（别背原文），点「说」
- [ ] 出现「正在针对你这句话组织反驳…」→ 然后给出反驳，**带 DeepSeek 徽标**
- [ ] 关键验收：**AI 的反驳里引用了你原话里的具体词**，并以一个**问句**结尾
- [ ] 再回一句你的看法（第 2 回合）→ AI 继续针对**你新说的那句**反驳
- [ ] 切强度 🌤温和 / ⚖️适中 / 🔥激烈 → 语气明显不同
- [ ] 第 3 回合后 → 「🤝 达成共识，生成图谱」能走完

> 想确认它真走了 DeepSeek：诊断条或 `http://localhost:8787/api/ai/models` 看 `order: ["deepseek","zhida"]`。

## 3. 部署到腾讯云后复测

1. `node server.js`（`PORT` 可用环境变量改），确认日志里知乎 ✅ / DeepSeek ✅。
2. 前面挂 Nginx 时**必须转发 WebSocket 升级头**，否则房间退化成"只有自己看得见"：
   ```nginx
   location / {
     proxy_pass http://127.0.0.1:8787;
     proxy_http_version 1.1;
     proxy_set_header Upgrade $http_upgrade;
     proxy_set_header Connection "upgrade";
     proxy_set_header Host $host;
   }
   ```
3. 线上复测只需跑 **2.6 的多人验证**（换两台设备/两个网络）+ **2.4 知乎原文** + **2.8 抬杠**。
4. 用手机流量（不是 WiFi）访问一次，确认真实外网可达。

## 4. 出问题时的定位顺序

| 现象 | 先看哪里 | 常见原因 |
|---|---|---|
| 点「炼金宇宙」没反应 | `?diag=1` 诊断条 | 首次加载 three.js 慢；或 WebGL 不可用（诊断条会写） |
| 3D 一片黑 | 控制台 | 显卡/驱动；宇宙会给出可读错误提示，不会静默 |
| AI 不回答 / 显示"本地兜底" | `GET /api/health`、`GET /api/ai/models` | 后端没起、key 失效（401）、余额不足（402）、限流（429） |
| 抬杠没走 DeepSeek | 启动日志、`/api/ai/models` | `order` 第一位不是 `deepseek` |
| 知乎原文拉不到 | `GET /api/zhihu/quota` | 额度用尽（`hot_list` 100/天、`question_answers` 100/天、`zhihu_search` 5000/天，均已做 TTL 缓存） |
| 房间看不到别人 | 两个窗口的在线人数 | 后端没起 / Nginx 没转发 WS 升级头 / 两人点的不是同一个话题 |
| 批注点了没用 | 是否选中了"同一段内"的文字 | 跨段落选区不支持（会提示"请在一段原文内选择"）；用段落 ✏️ 更省事 |
| 极光看着糊 | `?fps=1` 看帧率 | 设备性能不足时后处理会降级（这是设计），可关 `#uniGrade` |
| 页面样式全乱 | 是否改了 `index.html` 的 CSS | 本次 CSS 全部是**追加块**，老规则应保持原样 |
