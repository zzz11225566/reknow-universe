## 三、怎么运行

```bash
# 1) 后端（含知乎开放数据 + LLM + 多人实时）
node server.js            # → http://localhost:8787

# 2) 也可以直接双击 index.html（file://）
#    3D / 学习闭环 / 演示数据全部可用；AI、知乎、房间会自动走本地兜底并提示"未连接后端"
```

`env`（根目录，已在 `.gitignore` 里）需要两个值：

| 变量 | 状态 | 说明 |
|---|---|---|
| `ZHIHU_ACCESS_TOKEN` | ✅ 实测可用 | 知乎开放平台 Access Secret（`developer.zhihu.com`），40 位十六进制 |
| `DEEPSEEK_API_KEY` | ✅ 实测可用 | DeepSeek key，`sk-` + 32 位十六进制（共 35 字符）。启动即验证，日志会打印可用模型与余额 |
| `DEEPSEEK_MODEL`（可选） | 默认 `deepseek-chat` | 该账号实际可用模型为 `deepseek-flash` / `deepseek-v4-pro`；`deepseek-chat` 被服务端别名到 `deepseek-flash`（实测 ~1.5s，话术紧凑，**推荐**）。`deepseek-v4-pro` 是推理型（先写 `reasoning_content` 再出正文，~5-6s，更贵），代码已自动抬高 token 预算兼容，但演示不建议 |
| `DEEPSEEK_DEBATE_MODEL`（可选） | 默认同 `DEEPSEEK_MODEL` | 只想给「AI 抬杠」换更强模型时用 |
| `PORT`（可选） | 默认 8787 | |

补充：`GET /api/ai/models` 可随时查模型列表 + 余额 + 探针结果（5 分钟缓存，`?force=1` 强刷）；`/api/health` 里也带 `deepseek.verified / models / balance`。

腾讯云部署要点：
1. `PORT` 可用环境变量覆盖（默认 8787），建议前面挂 Nginx 做 80/443 + WebSocket 转发（记得 `proxy_set_header Upgrade/Connection`）。
2. **必须放行 WebSocket**，否则多人热点房间退化为"本地回显"。
3. 单实例即可；多人房间是**进程内存**实现，多实例部署需要外接 Redis 广播（见第八节）。
