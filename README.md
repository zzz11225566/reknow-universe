## 一、两种运行方式

### 方式一：纯离线演示（推荐给评委，双击即用）
直接双击打开 `index.html`（file://）：
- 3D 引擎 Three.js（r160）已**本地内置**在 `vendor/`，无 CDN、无构建、无需安装；
- 热榜 / 搜索 / 天气 / 圈点批注全部用**内置数据自洽运行**；
- AI 对话 / 知乎原文 / 多人房间会自动走本地兜底并提示"未连接后端"，**不会报错**。

### 方式二：完整能力演示（后端）
```bash
node server.js
# 打开 http://localhost:8787
```
前端自动探测后端并点亮右上角绿色「实时」徽标，此时额外获得：
- **知乎开放平台真实数据**：实时热榜 / 站内搜索 / 问题回答 / 我的收藏 / 收藏夹 / 额度查询
  （`/api/zhihu/hot|search|answers|original|collections|favlists|quota`，全部带 TTL 缓存护额度）；
- **真实大模型**：`/api/ai/chat`、`/api/ai/chat/stream`（SSE）、`/api/ai/debate`（贴合用户原话的抬杠）；
- **多人实时**：`/ws` 双向 WebSocket，热点话题房间实时互通 + 房间内 `@ai` 广播；
- 环境推送：天气/温度按真实时间变化（含新增的雷暴档）。

> server.js 为**纯 Node 零依赖**实现（静态托管 + REST + SSE + WebSocket），无需 `npm install` 即可部署（腾讯云放行端口或前面挂 Nginx，记得转发 WebSocket 升级头）。

## 四、给开发者的说明

1. **app.js 是含两代代码的单体**（前半为基础 + 启动，后半 v6 增补靠函数声明覆盖同名实现，见文件内注释）。宇宙功能**零侵入**：只在外层包裹 `showView`，新增代码全部在 `universe.js` / `boot.js`。
2. `vendor/three.min.js` 为 r150+ 的**兼容别名构建**，控制台会打印一条弃用提示（`Scripts "build/three.js"... deprecated`），不影响功能；如介意可用 `node_modules/three` 的 ESM + importmap（需 http 服务）。
3. 新增存储键：`rkUni6`（宇宙偏好：天气）、`rkUniOrig`（各篇原文段落 HTML + 批注），与旧键 `rkSave` / `rkCustom` 互不干扰。
4. 演示热榜 / 环境为**模拟数据**（server.js 内注释标明替换点）：接入知乎开放平台（OAuth：收藏夹 / 收藏内容 / 创作）与天气 API（OpenWeatherMap / 和风）时，遵守 robots.txt、最小授权与赛事合规。
5. 天气数值与昼夜调色在 `universe.js` 顶部 `WEATHERS` / `todOfHour` 中集中定义，想调风格改这里即可。
6. 真机演示小抄：顶栏 → 炼金宇宙 → 点「🌧️」看 1.5s 过渡 → 开「🔥 热榜」点第一条看镜头飞行 → 点星体「📖 看原文·圈点」演示选区高亮 + 📝 批注 → 关阅读器「⛏ 开始学这篇」回到学习闭环。

## 五、版本
v7.0.0 · 素材（看山 GIF / 三视图）版权归知乎官方所有，仅赛事用途。

**v7 已知边界**（详见 `docs/v7-交付说明.md` 第五节）：
- `env` 里的 `DEEPSEEK_API_KEY` 与 `ZHIHU_ACCESS_TOKEN` **均已实测可用**（2026-09-13）；启动日志会打印鉴权结果、可用模型与余额。模型分工：**AI 问答 `zhida → deepseek`，AI 抬杠 `deepseek → zhida`**。若 DeepSeek 失效（401 余额/限流等），后端会**自动降级到知乎直答**，功能不受影响。默认模型 `deepseek-chat`（别名到 `deepseek-flash`，~1.5s）；`deepseek-v4-pro` 是推理型，已自动兼容但更慢更贵。
- 知乎开放平台不提供"按 answer id 取全文"的接口，原文为**长摘要/正文节选**（已做三级降级 + 原链接跳转）。
- 多人房间是**进程内存**实现：单实例完美，重启清空，多实例需接 Redis。
- 看山动作用的是官方 6 个固定 GIF（项目红线：`assets/` 不动），"更卡通"只能做表现层增强。
