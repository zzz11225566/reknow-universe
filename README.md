# 炼知 ReKnow v6 · 炼金宇宙版

> 知乎黑客松 2026「知识炼金场」赛道 · 把「收藏」炼成「回答」

在 v5 单文件 Demo（收藏夹 → 拆解 → 四种学习方式 → DIY 图谱 → 回流）之上，把学习体验升维成一座**沉浸式 3D 知识宇宙**：收藏 = 星体、理解 = 炉火、天气与真实时间会真实地改变你的学习场景。

## 一、两种运行方式

### 方式一：纯离线演示（推荐给评委，双击即用）
直接双击打开 `index.html`（file://）：
- 3D 引擎 Three.js（r160）已**本地内置**在 `vendor/`，无 CDN、无构建、无需安装；
- 热榜 / 搜索 / 天气 / 圈点批注全部用**内置数据自洽运行**。

### 方式二：实时联动演示（可选后端）
```bash
node server.js
# 打开 http://localhost:8787
```
前端自动探测后端并点亮右上角绿色「实时」徽标：
- 热榜每小时重排、`/api/hotlist` 可查；
- 模拟环境每 72 分钟变化（天气 / 温度 / 城市），经 **WebSocket** 实时推送到 3D 场景；
- `/api/search?q=费曼` 全站搜索。

> server.js 为**纯 Node 零依赖**实现（静态托管 + REST + WebSocket），无需 `npm install`。

## 四、给开发者的说明

1. **app.js 是含两代代码的单体**（前半为基础 + 启动，后半 v6 增补靠函数声明覆盖同名实现，见文件内注释）。宇宙功能**零侵入**：只在外层包裹 `showView`，新增代码全部在 `universe.js` / `boot.js`。
2. `vendor/three.min.js` 为 r150+ 的**兼容别名构建**，控制台会打印一条弃用提示（`Scripts "build/three.js"... deprecated`），不影响功能；如介意可用 `node_modules/three` 的 ESM + importmap（需 http 服务）。
3. 新增存储键：`rkUni6`（宇宙偏好：天气）、`rkUniOrig`（各篇原文段落 HTML + 批注），与旧键 `rkSave` / `rkCustom` 互不干扰。
4. 演示热榜 / 环境为**模拟数据**（server.js 内注释标明替换点）：接入知乎开放平台（OAuth：收藏夹 / 收藏内容 / 创作）与天气 API（OpenWeatherMap / 和风）时，遵守 robots.txt、最小授权与赛事合规。
5. 天气数值与昼夜调色在 `universe.js` 顶部 `WEATHERS` / `todOfHour` 中集中定义，想调风格改这里即可。
6. 真机演示小抄：顶栏 → 炼金宇宙 → 点「🌧️」看 1.5s 过渡 → 开「🔥 热榜」点第一条看镜头飞行 → 点星体「📖 看原文·圈点」演示选区高亮 + 📝 批注 → 关阅读器「⛏ 开始学这篇」回到学习闭环。
