1我们解决什么问题

知乎用户的典型行为是「收藏即终点」：收藏夹囤了几百篇，回看率低；真要讲、要写时组织不起来。缺的不是内容，而是把别人的好内容变成自己的能力的那道工序。

🐿️收藏夹吃灰

收藏 ≠ 学会，囤积焦虑远大于消化。

🧠看完就忘

缺少主动回忆与间隔复习。

✍️输出无门

想写回答怕重复、组织不起观点。

🧩碎片无体系

知识散落各篇，形不成自己的地图。

2v6 炼金宇宙：四个新体验

🌌沉浸式 3D 宇宙

主题 = 星球（大小随热度）、原文 = 炼金链路（光点流动）、中心 = 炼金炉（炉火随经验值燃烧）、看山 = 向导（会随天气换动作）。点星体即可回到「拆解 → 学懂 → 图谱 → 回流」完整闭环。

🌦️天气系统

晴天 / 多云 / 雨夜 / 雪夜 / 极光一键切换，1.5 秒平滑过渡：光影色温、星尘密度与流速、雨雪极光粒子、雾浓度与背景全部实时联动。

🕐环境数据驱动

真实时间决定昼夜（黎明 / 白昼 / 黄昏 / 深夜）自动调色；接入可选后端后，真实城市天气与热榜会通过 WebSocket 实时推送并自动改变场景。

✏️原文圈点勾画

每颗星 / 每篇拆解都可在「知乎问答样式」原文上选中文字做 黄 / 蓝 / 粉 三色高亮、加旁注批注，自动保存，下次打开自动恢复。

3热榜 · 搜索 · 数据驱动场景

  • 🔥 知识热榜：宇宙右上角热榜抽屉，按「热度」排序（星体大小即热度）；点榜单直达对应星体并聚焦视角。
  • 🔍 全站搜索：按题目 / 答主 / 分类 / 关键词过滤星海，其余星球淡出；后端在线时同步检索热榜 API。
  • 📡 后端可选：自带 server.js（纯 Node、零依赖）——静态托管 + /api/hotlist + /api/search + /api/env + WebSocket 实时推送；前端自动探测，连上即点亮「实时」徽标。无后端时全部用本地数据自洽运行，双击 HTML 也能完整演示。
  • 🗂 数据说明：赛事演示使用预置示例收藏（12 篇 + 自定义），真实接入时替换为知乎开放平台（OAuth 收藏夹 / 收藏内容 / 创作接口）与天气 API（OpenWeatherMap / 和风），并遵守 robots.txt 与最小授权。

8交付清单与运行方式
